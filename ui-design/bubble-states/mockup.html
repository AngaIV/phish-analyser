Hover · tooltip
  • Fail-safe: the dashed grey ring is never green — when headers are missing the tool says so rather than showing an all-clear.
  • No tick on the safe state (D-011). An earlier revision used a tick and described it as a deliberate accessibility choice. It was removed: a tick asserts the message is safe, and the measured false-green rate is 17% on the dev split and 33% on the holdout. The safe state shows 0 — a count — and is labelled "No issues found", never "Safe". The wording matters as much as the glyph: it describes what the engine did, not what the message is.
  • Accessibility: the number is never the only signal — colour is paired with the ring fill, a dash for unknown, or the sweep animation for analysing.
  • Snoozed / disabled: the bubble fades out rather than showing a muted state over the message.
